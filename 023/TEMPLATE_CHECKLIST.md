# Before publishing your package

- [ ] Choose a unique distribution name in `pyproject.toml` and update the import-package directory under `src/`.
- [ ] Replace the example greeting API and tests with your package's real functionality.
- [ ] Set the supported Python range, version, description, command-line entry points, and runtime dependencies deliberately.
- [ ] Choose and include a license before public distribution; this starter intentionally does not select one for you.
- [ ] Install the package in a clean environment, run the test suite, and build/check the wheel before publishing.
- [ ] Remove any demo or placeholder metadata that no longer describes your project.
