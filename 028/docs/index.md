# Project Docs Starter

This sample site shows how a small project can keep setup, usage, and publishing guidance together in a searchable documentation site.

## Start here

- [Getting started](getting-started.md) explains how to install and preview this site.
- [Writing pages](writing-pages.md) explains how to add content and update navigation.
- [Publishing](publishing.md) covers the static build and a safe pre-release checklist.

## Why use a separate docs site?

A short repository README helps visitors orient themselves. A documentation site works better when instructions grow into multiple topics, need clear navigation, or need a local preview before publication.
