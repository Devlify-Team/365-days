# Project README Gallery

A browsable collection of project README previews. Edit `projects.json` and rebuild with `python3 scripts/build_gallery.py`.

## Data

### [CSV Cleanup Helper](examples/data-helper/README.md)

A focused Python utility that checks a CSV file for missing values and inconsistent column names before an analysis begins.

## Developer tools

### [CLI Task List](examples/cli-task/README.md)

A small command-line app for organizing personal tasks in a local text file, with no account or network service required.

## Web

### [Responsive Web Starter](examples/web-starter/README.md)

A minimal static site starter with an accessible page shell, reusable CSS tokens, and a simple mobile navigation pattern.
