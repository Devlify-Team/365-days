# Notebooks

Use notebooks for exploratory work, questions, and compact visual summaries; move logic that needs reuse or testing into `src/`. Suggested names use a small phase/sequence and an initial or short author tag, for example `0.01-initial-data-review.ipynb`. Keep outputs intentional, record the data source and transformations, and do not commit sensitive inputs or outputs.

This scaffold intentionally includes no notebook or sample dataset. First identify an authorized, real dataset and record its source and use conditions; the notebook directory is a starting point, not synthetic analysis.
