# Practice a documentation contribution

This sample page gives you a safe place to practice a focused Markdown edit. Read the [style guide](../DOC_STYLE_GUIDE.md) before changing it.

## Choose a small improvement

Look for a sentence that could be clearer, a missing context sentence, or a local link that needs correction. Make one targeted change and keep the instructions consistent with the rest of the project.

## Verify the result

Run the local Markdown checker and the test suite from this folder. Then inspect the rendered page and ask whether a first-time reader can follow it without guessing.
