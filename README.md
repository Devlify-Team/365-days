# 365 Days

Daily projects for Devlify-Team, kept together in one repository.

## Project structure

Each project lives in its own zero-padded folder: `001/`, `002/`, `003/`, and so on. Project names appear in this index and in each folder's README. No separate repository is needed for each project.

| Number | Project | Topic | Deliverable |
| --- | --- | --- | --- |
| [001](001/) | Create GitHub profile README | GitHub Setup | Exercise guide and editable profile README template |

## Daily continuation

The existing daily schedule is set for **05:00 Africa/Lagos**. This repository does not create a second schedule or a GitHub Actions timer.

Project `001` is the initial seed. The first scheduled run should start with `001`, check the existing files, and preserve or complete that project without overwriting it or creating a duplicate. Later runs continue with `002`, `003`, and onward, using the challenge tracker. Preserve previous work and keep this index updated.

## Day 001 note

The profile README exercise is intentionally stored inside `001/`. It is a template, not a live personal profile README. GitHub requires a separate public repository matching a personal username to display a README on that person's profile; this challenge does not create that separate repository.
